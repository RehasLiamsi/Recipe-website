# 🍽️ Recipe Website

This is a simple, responsive static recipe website built using HTML, CSS, and JavaScript. It displays multiple recipes, allows users to view details, and includes a rating feature for individual dishes.

## 📁 Project Structure

```
Recipe-website-main/
├── index.html                  # Homepage
├── allRecipes.html            # Displays all available recipes
├── rateRecipe.html            # Page for rating a recipe
├── spaghettimeatballs.html    # Individual recipe page
├── css/
│   └── styles.css             # Site-wide styles
├── js/
│   ├── allRecipes.js          # Logic for listing recipes
│   ├── rateRecipe.js          # Logic for rating recipes
│   └── spaghettimeatballs.js  # Logic for single recipe page
├── data/
│   └── data.json              # JSON file with recipe data
└── img/
    ├── *.jpg / *.png          # Image assets for recipes and UI
```

## 🧰 Tech Stack

- **HTML5** – for structure
- **CSS3** – for styling
- **JavaScript (Vanilla)** – for dynamic behavior
- **JSON** – for storing and loading recipe data

## 🔍 Features

- 📜 Browse a collection of recipes
- ⭐ Rate individual recipes
- 🖼️ Image-rich content for better presentation
- 📱 Responsive layout (mobile-friendly)

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser to view the homepage.
3. Navigate to different pages to explore recipes and rate them.

## 📌 Notes

- This is a front-end only project.
- No backend or database integration is included.
- Ensure JavaScript is enabled in your browser for full functionality.
